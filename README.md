# 🛍️ وانیلا شاپ

یک فروشگاه اینترنتی مدرن و فول‌استک ساخته‌شده با **Django** و طراحی‌شده برای استفاده در یک فروشگاه واقعی.

### ✨ قابلیت‌ها

* 🔐 ورود و ثبت‌نام با شماره موبایل و OTP + احراز هویت JWT
* 🛒 سبد خرید، علاقه‌مندی‌ها و انواع مختلف محصول
* 📦 مدیریت سفارش، رزرو، مرجوعی و بازپرداخت
* 💳 اتصال به درگاه پرداخت آنلاین
* 🖼️ بهینه‌سازی تصاویر و پشتیبانی از چند تصویر برای محصول
* 🔎 جست‌وجو، دسته‌بندی و صفحه‌بندی محصولات
* 👤 پروفایل کاربر و مدیریت آدرس‌ها
* 🎁 تخفیف، هزینه ارسال و امکانات فروشگاهی
* 📝 بخش وبلاگ و مدیریت محتوا
* 🛠️ پنل مدیریت اختصاصی Django
* 🗄️ پشتیبانی از PostgreSQL
* 📱 طراحی واکنش‌گرا برای موبایل و دسکتاپ

### 🧰 تکنولوژی‌ها

**Python · Django · Django REST Framework · PostgreSQL · JavaScript · HTML · CSS**

# 🛍️ Vanilla Shop

A modern full-stack e-commerce website built with **Django** and designed for a real-world online store.

### ✨ Features

* 🔐 Phone OTP authentication & JWT-based login
* 🛒 Shopping cart, wishlist & product variants
* 📦 Order management, reservations, returns & refunds
* 💳 Online payment integration
* 🖼️ Product image optimization & multiple product images
* 🔎 Product search, categories & pagination
* 👤 User profiles & address management
* 🎁 Discounts, shipping rates & promotional features
* 📝 Blog & content management
* 🛠️ Custom Django admin panel
* 🗄️ PostgreSQL database support
* 📱 Responsive design for desktop & mobile

### 🧰 Tech Stack

**Python · Django · Django REST Framework · PostgreSQL · JavaScript · HTML · CSS**
